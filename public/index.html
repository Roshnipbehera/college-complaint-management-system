REST API Specifications

Comprehensive endpoint documentation for the College Complaint Management System.

🔐 Authentication Endpoints

Method Endpoint Description Access
POST /api/auth/register Registers new student with bcrypt hashed password Public
POST /api/auth/login Authenticates credentials, returns JWT & HTTP-only cookie Public
GET /api/auth/me Fetches currently logged-in user profile & role Authenticated
POST /api/auth/logout Clears HTTP-only session cookie Authenticated

📋 Complaint CRUD & Lifecycle Endpoints

Method Endpoint Description Access
GET /api/complaints List complaints (supports status, category, priority, search, page, limit) Public / Authenticated
GET /api/complaints/:id Fetch single complaint by ID with history & comments Public / Owner / Staff
POST /api/complaints Create new complaint Student / Authenticated
PUT /api/complaints/:id Update complaint attributes Owner / Staff / Admin
DELETE /api/complaints/:id Delete complaint Owner / Admin
POST /api/complaints/:id/assign Assign complaint to staff Staff / Admin
POST /api/complaints/:id/comments Add threaded reply / comment Authenticated
