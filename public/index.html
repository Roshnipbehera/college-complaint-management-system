How It Works

Transparent 3-Step Redressal Workflow

Every grievance follows an auditable lifecycle from submission to verified resolution.

1

Register Your Grievance

Select the relevant department category (Academics, Hostel, Labs, Library, etc.), describe the issue clearly, and set the urgency priority.

2

Department Triage & Inquiry

Your grievance is routed directly to the designated faculty supervisor or facility warden within 24 hours for official on-ground inspection.

3

Verified Resolution & Receipt

Receive live status updates, participate in threaded resolution discussions, and download an official institutional receipt.

🚨 24x7 Anti-Ragging & Emergency Support

Our institution enforces a strict zero-tolerance policy against ragging, harassment, and campus safety hazards. Emergency grievances are prioritized immediately.

Technical API Reference

REST API endpoints powering the College Grievance Management System.

🔐 Authentication Endpoints

Method Endpoint Description Access
POST /api/auth/register Registers new student with bcrypt hashed password Public
POST /api/auth/login Authenticates credentials, returns JWT & HTTP-only cookie Public
GET /api/auth/me Fetches current authenticated profile & role Authenticated
POST /api/auth/logout Clears HTTP-only session cookie Authenticated

📋 Complaint CRUD & Lifecycle Endpoints

Method Endpoint Description Access
GET /api/complaints List complaints with multi-criteria filtering Public / Authenticated
GET /api/complaints/:id Fetch single complaint by ID with full audit trail Public / Owner / Staff
POST /api/complaints Create new complaint Student / Authenticated
POST /api/complaints/:id/status Update lifecycle status with audit remarks Staff / Admin
POST /api/complaints/:id/comments Add threaded reply / comment Authenticated
