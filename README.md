# Installation

Install dependencies:

npm install

Create a .env file:

PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=YOUR_PASSWORD
DB_NAME=college_complaint_management
DB_PORT=3306

Run database/schema.sql in MySQL Workbench.

Then start the server:

npm start
